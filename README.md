# Agent Desk

Single-file dashboard for a multi-agent BTC paper-trading desk. Pure HTML, no build step.

- Starts with a $2,000 simulated bank.
- All data is random and generated in the browser. Nothing is a real trade.
- Next step: replace `tick()` in `index.html` with a Supabase realtime subscription.

Deploy: connect this repo to Netlify, publish directory `/`.
